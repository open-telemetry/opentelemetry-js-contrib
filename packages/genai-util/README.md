# OpenTelemetry GenAI Utilities

[![NPM Published Version][npm-img]][npm-url]
[![Apache License][license-image]][license-image]

This is an internal utility package providing shared data models, invocation lifecycle handlers, metric instruments, and semantic convention constants for OpenTelemetry Generative AI instrumentations in JavaScript / TypeScript.

## Installation

```bash
npm install --save @opentelemetry/genai-util
```
